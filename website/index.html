Run queries, inspect schemas, export results — from any machine.

Who this is for

Hackathon teams, solo developers, and anyone prototyping an app that needs Postgres immediately. Persistence, a volume-backed database, and a UI for debugging — without exposing Postgres to the public internet.

How it fits together

  1. Add PostgreSQL with a volume on Railway.
  2. Deploy this repo as the PgWeb service.
  3. Set DATABASE_URL to the Postgres reference variable.
  4. Point your app at the same Postgres reference.

Security note

PgWeb is public in this template so you can reach it quickly. For anything beyond experimentation, restrict access — authentication proxy, IP allowlisting — before storing real user data.
